# NapariSBT interface help

The interface help is now organised into the dedicated
[NapariSBT no-code guide](../napari_sbt/index.md).

Start with [Your first session](../napari_sbt/first_session.md), then
[Home and Workspace](../napari_sbt/workspace.md). Each workflow has its own page,
including [Explore](../napari_sbt/explore.md),
[Population QC](../napari_sbt/population_qc.md),
[Scanpy plotting](../napari_sbt/scanpy_plotting.md), and
[Dataset Maintenance](../napari_sbt/dataset_maintenance.md).

These pages reuse the same instructions as the in-app **Help** buttons.
Their coloured headings match the interface boxes. **Smaller text** and
**Larger text** in the popup adjust the help text without changing your data.
