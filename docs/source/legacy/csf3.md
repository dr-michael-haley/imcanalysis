# Retired CSF3 notes

The former `CSF3/README.md` described an early set of separate scripts such as
`preprocesing.py`, `createmasks.py`, and `basic_process.py`. Those entry points,
their config examples, and their output paths no longer represent the current
pipeline.

For a new or maintained analysis, use:

- [CSF3 setup](../getting_started/hpc.md)
- [Pipeline workflow](../pipeline/workflow.md)
- [Generated SLURM stage reference](../pipeline/stages/index.md)
- [Generated configuration reference](../reference/configuration/index.md)

The `CSF3/` directory remains in the repository only for historical context.
Do not copy its old job commands or config blocks into a current project.
