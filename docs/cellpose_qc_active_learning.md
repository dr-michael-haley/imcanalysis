# CellPose active-learning QC viewer

`napari_cellpose_qc_active_learning` is a Napari tool for object-level QC of CellPose-SAM IMC segmentation masks. It does not recalculate morphology, intensity, or CellPose features. It consumes the per-object feature table and feature dictionary produced by `SpatialBiologyToolkit/scripts/cellpose_sam.py`.

## Required inputs

- `images`: default `images`. The preferred layout matches `napari_imc_explorer`: `images/<ROI>/<channel>.tiff`. A direct `images/<ROI>.tiff` layout is also supported.
- `masks`: default `masks`, with one mask TIFF per ROI.
- Feature table: usually `masks/CellposeSAM_cell_metrics.csv`.
- Feature dictionary CSV: usually `masks/CellposeSAM_cell_metrics_feature_dictionary.csv`.
- QC output folder: default `qc_classifier`.

## Launch

```python
from SpatialBiologyToolkit.napari_cellpose_qc_active_learning import napari_cellpose_qc_active_learning

viewer, handles = napari_cellpose_qc_active_learning(
    masks_folder="masks",
    image_folders="images",
    feature_table_path="masks/CellposeSAM_cell_metrics.csv",
    feature_dictionary_path="masks/CellposeSAM_cell_metrics_feature_dictionary.csv",
    output_folder="qc_classifier",
)
```

Or from a shell:

```bash
python -m SpatialBiologyToolkit.napari_cellpose_qc_active_learning --masks masks --images images
```

## Workflow

1. Load/reload inputs in the `Controls` panel.
2. Select an ROI and click `Load ROI`. The default image layer prefers the first ROI image whose channel name or filename contains `DNA`.
3. In `Labels`, choose `flag as good`, `flag as artifact`, `erase flagged label`, or `inspect only`, then click cells in the mask.
4. Optional: edit the annotation-mode shortcut keys in `Labels` and click `Apply annotation shortcuts`.
5. Use `Bulk flagging` to stage low-score cells as good or high-score cells as artifact after a model has produced scores.
6. Click `Confirm flagged labels` to add staged labels to the confirmed training set.
7. In `Feature model`, choose feature categories from the dictionary, validate inputs, and train/retrain the classifier.
8. Apply the classifier to the current ROI or all ROIs.
9. Use the `Status` traffic lights to track whether retraining, scoring, or ROI review is still needed.
10. Export cleaned masks from `Export` when the workflow indicators are green.

## Label states

- `confirmed_good`: known good training cell, dark green.
- `confirmed_artifact`: known artifact training object, dark red.
- `flagged_good`: candidate good cell, bright green.
- `flagged_artifact`: candidate artifact, bright red.

Flagged labels are not used for training until explicitly confirmed.
The `Labels` panel includes contour controls for each label state. Confirmed states default to contour `0`; flagged states default to contour `2`.
It also includes initial visibility controls for the Confirmed, Flagged, Probability, All_cells, and DNA layer groups. Confirmed, Flagged, Probability, and DNA default to visible; All_cells defaults to hidden. These settings are applied when a ROI is loaded or when a new probability layer is created; manual Napari layer visibility changes remain available afterward.

## Status traffic lights

The `Status` panel uses green/orange/red indicators for:

- flagged labels still awaiting confirmation
- whether the loaded classifier matches the confirmed label files
- whether the current ROI score was generated by the current classifier
- how many ROIs have current classifier scores
- how many ROIs have both confirmed good and confirmed artifact examples
- how many ROIs have been loaded/reviewed in the viewer with current classifier scores

## Score convention

`artifact_probability = 0` means likely good cell.

`artifact_probability = 1` means likely artifact.

Scores are object-level classifier outputs mapped back onto the mask for display.

## Saved files

The original masks and images are never overwritten. Outputs are written under the QC folder:

- `labels/<ROI>_labels.csv`
- `scores/<ROI>_scores.csv`
- `models/classifier_latest.joblib`
- `models/<MODEL_ID>.joblib`
- `models/<MODEL_ID>_metadata.json`
- `metadata/<ROI>_scores_metadata.json`
- `metadata/<ROI>_review_metadata.json`
- `masks_cleaned/<ROI>_cleaned_mask.tiff`
- `exports/<ROI>_cell_qc.csv`
- `logs/qc_session_log.txt`

Cleaned masks are exported as 16-bit TIFFs. If preserving original label IDs would exceed the 16-bit label range, export with relabeling enabled so the tool can write a label mapping table.

Reload the viewer with the same folders to resume a session.

## Assumptions

The upstream feature table uses `ROI` and `ObjectNumber` as identifiers. The upstream dictionary uses `feature`, `type/source`, and `description`. Feature categories marked as identifiers, metadata, or segmentation configuration are excluded from model input by default unless a future dictionary explicitly marks them as model features.
