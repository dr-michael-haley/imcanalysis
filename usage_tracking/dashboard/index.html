How usage is counted

Each explorer records an activity day when someone agrees to daily reporting. Reopening the app that day usually counts once. Each app counts separately. These totals measure activity rather than unique people.

Distinct names count different self-reported names across the selected apps and dates. People can share a name. Anonymous activity days count daily records from browsers where the user chose to remain anonymous.

Dataset opens count each time an explorer successfully reads a local dataset, including repeat opens. The MCD example has its own demo count. A figure export counts when the app generates an image for download.

Action reporting is a separate choice in each explorer’s Usage preferences. The public report contains only aggregate counts. Names, filenames and research data stay out of the report.
