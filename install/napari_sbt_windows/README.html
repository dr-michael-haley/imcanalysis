Windows startup guide

NapariSBT for Windows

The ZIP includes NapariSBT and its Python environment. You do not need to install Python or Conda, or run as administrator. Choose one of the three startup options below, depending on what your computer permits.

Start NapariSBT

  1. Extract the entire ZIP into a folder on a local drive that you have access to and can save files in.
  2. Open the extracted folder and double-click NapariSBT.exe. It should be beside python.exe, with Lib, Library, and Scripts folders alongside it. Do not run the launcher from inside the ZIP.
  3. On first launch, a small progress window says Preparing NapariSBT while the environment is configured for its new location. This can take a little time. Later launches skip that preparation.
  4. Use Home to choose a dataset or open a workspace. Images and masks may remain on a network drive. There is no command window to manage.

Keep datasets and saved workspaces outside the application folder so they can be reused with future versions.

Backup: start with the batch file

If your computer permits batch files, double-click Start_NapariSBT.bat in the extracted folder. Keep its command window open while using NapariSBT. First-run setup is automatic; errors stay visible in that window.

The batch file needs start_naparisbt.py alongside it. It uses the same setup record as NapariSBT.exe, so you can switch between these updated launchers without repeating setup. If Windows blocks batch files, use the command-prompt instructions below only where your organisation permits running the bundled Python.

Start directly from Command Prompt

This option does not run NapariSBT.exe, Start_NapariSBT.bat, or Scripts\activate.bat. It still runs the bundled python.exe, which must be allowed by your computer's security policy. If that is blocked too, your IT team will need to approve a deployment; these commands do not override the policy.

  1. Extract the entire ZIP into the folder you intend to keep.

  2. Open the Windows Start menu, type Command Prompt, and open it normally. Do not choose Run as administrator. These instructions use Command Prompt (cmd.exe), rather than PowerShell.

  3. Enter the following command, replacing the example with your extracted folder. Keep the quotation marks if the path contains spaces:

    cd /d "D:\NapariSBT"

    If Windows says it cannot find that path, correct it before continuing.

  4. Enter:

    .\python.exe -E -s .\start_naparisbt.py

The helper prepares the environment on first use, then opens NapariSBT Home. Use these same two commands for later launches; setup is skipped automatically. Keep the command window open until you finish using NapariSBT. No separately installed Python, Conda activation, or manual conda-unpack command is needed.

If startup fails, copy the error text from this window when asking for help. To save the output to a file instead, replace the last command with:

.\python.exe -E -s .\start_naparisbt.py > "%USERPROFILE%\NapariSBT-startup.log" 2>&1

This overwrites NapariSBT-startup.log in your user folder each time. Progress messages go to the file, so the command window may appear quiet during startup.

Moving or updating the application

Keep the extracted application folder in the same location after first launch. To move it or install an update, extract the original/new ZIP into a fresh folder and run the included launcher. You can reopen your separately saved workspaces.

The launcher detects folders moved or renamed after its own first setup. It also asks for a fresh extraction if an older batch launcher prepared the folder, because that launcher did not record the installation location. Do not delete the setup marker files to bypass either check.

If startup fails

If the executable launcher shows an error, click Open logs folder and send the latest launcher-*.log file to the person who provided NapariSBT. The batch and command-prompt options show errors in their command window instead. Logs can include local paths and application output.

First setup needs a folder on a local drive that you have access to and can save files in. Running as administrator is unnecessary.

Institutional Windows security policies may block executables, batch files, or Python scripts even though they do not require admin rights. If Windows blocks them, ask your IT team or distributor about an approved/signed build. The launcher does not disable or change Windows security settings.
